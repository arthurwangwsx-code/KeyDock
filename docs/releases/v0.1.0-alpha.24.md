# KeyDock 0.1.0-alpha.24

桌面自定义保存与删除的一致性改进：收藏失败会保留原状态并在启动台提示；动作菜单显示实际操作标题；应用动作与快捷键、收藏、别名、最近使用统一保存，删除前检查引用，旧编辑不会重新创建已删除动作。

配置升级到schema3。首次成功保存时迁移已确认的旧应用动作，原文件保留；未知来源保持只读。升级后的数据不能交给仅支持schema1／2的旧版本，安装／回退脚本会检查并拒绝。

独立桌面验收会话增加固定字段诊断。模型设置继续支持全局、场景与定义覆盖；推荐目录和思考参数于2026-11-26按官方资料复核。

Apple Silicon预发行版。完整系统／视觉、真实插入与实体快捷键、最低系统及长期稳定性仍在验收；Agent运行总预算、持久步骤及原图附件等工程仍按原建设账本推进。签名与发布事实见[实施记录](https://github.com/arthurwangwsx-code/KeyDock/blob/master/docs/implementation/application-action-configuration-2026-11-26.md)。
