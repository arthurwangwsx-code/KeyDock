# KeyDock 0.1.0-alpha.11

本版本包含以下增量。实际公开、安装和验证状态见项目状态总账与GitHub Release。

- 设置增加独立“内置工具”页面，可开关计算与单位换算、命令行工具、文件搜索，并保留已有定义、目录、收藏、别名和快捷键偏好。
- 三类工具迁入编译期受信版本目录；缺失或错版实现拒绝运行，旧查询和等待选区的旧快捷键不会在重新启用后复活。
- Launcher和Tools共用计算与文件搜索实现。计算复制保持一次写入；文件结果按具体查询、目录和对象身份复核后才在Finder显示。
- 命令行开关同时约束新Workflow／Agent。已运行任务仍使用原参数、契约版本和审批；升级改变CLI契约后，计划任务需重新审核。
- 修复空目录Return搜索持续加载、旧文件结果被新查询升级，以及等待原选区时AI动作定义被替换的问题。
- 中英设置页、禁用反馈、重启持久化和辅助名称完成原生子集复查。

真实外部AI仍按用户决定稍后配置。完整视觉、真实IME／VoiceOver、权限下跨应用插入／窗口控制、多屏和长期性能仍需独立验收。技术支持与隐私请求：arthur.wang.wsx@gmail.com。
