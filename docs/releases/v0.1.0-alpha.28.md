# KeyDock 0.1.0-alpha.28

当 AI 用量记录达到保留期限、条数或容量上限时，KeyDock 会同时清理对应任务中保存的用量数字。任务本身和用户配置的 token 阈值继续保留。打开旧任务时，预算卡会说明哪些用量已经无法核实。

在隐私设置中清除用量时，占用中的记录会延后处理。正常退出会等待已接收的写入与任务释放，再重试延后项。若应用意外退出，用户可以再次清除。存储读取或删除失败时会显示部分完成，清除后产生的新记录按新的事实显示。

工作流内某一步的记录过期后，后续步骤仍可生成新用量。父任务使用仍可核实的记录，并保留汇总不完整的状态。

本次交付继续使用合成任务核验。实体快捷键、真实目标插入、完整多屏与辅助功能，以及费用停止阈值仍在后续验收范围中。[工程与验收记录](https://github.com/arthurwangwsx-code/KeyDock/blob/master/docs/implementation/retention-shutdown-2026-11-26.md)
