# KeyDock v0.1.0-alpha.7

本增量为独立剪贴板面板加入有序多选合并、准确预览和可配置主动作。完整产品验收仍为PARTIAL；是否正式发行以GitHub Release及状态总账为准。

- 圆形选择按钮或搜索框Shift-Return加入／移出当前项，跨查询保留清单，支持前移／后移、移除及清空。没有勾选项时继续操作当前单项。
- 合并清单最多20项、含分隔符最多1MiB；换行、空行、空格与无分隔符可选。数据库单事务保序读取，缺失／过期或超预算整批停止，不截断或悄悄跳过。
- 提交前重新读取并按实际UTF8字节核对已展示预览。正文改变时先更新预览，要求用户重新查看后主动提交；复制或插入只提交合并文本一次。
- 设置→剪贴板可选择Return为复制或插入，Command-Return执行另一项动作；原生菜单、底栏与搜索框共用解析。偏好独立存储，不自动开启记录。
- 复制改为检查系统写入、私有nonce及changeCount。失败保留面板并明确提示；不读取或恢复此前个人剪贴板。瞬态类型避免自采集。
- 历史复制与普通AI结果复制分开处理，保留后者继续作为显式AI剪贴板输入的能力。模型成功但自动复制失败时，保留完整结果和成功回执，单独提示复制未确认。

真实插入仍要求用户手动授予相应权限及原输入目标可验证。发出粘贴事件不证明外部应用消费或保存；没有逐项并发按键、自动重试或重启重放。物理全局快捷键、实际AX、多屏／Spaces、最低系统、完整视觉／辅助功能和真实模型质量仍需分别验收。
