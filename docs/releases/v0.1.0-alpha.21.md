# KeyDock v0.1.0-alpha.21

本版本将 AI 模型设置接入实际执行：全局默认、九类场景及动作／Agent 显式覆盖共用解析器。可选模型保留准确自定义 ID，区分继承、模型默认和明确思考强度；已知不兼容参数在发送前拒绝。目录按2026-11-26官方资料推荐 Sol／Astra／Terra／Luna，并为旧4.1 mini标记弃用。服务及账号实际可用性仍需用户配置后验证。

新增 Responses 文本和多轮工具会话。推理上下文仅在本次有界会话中驻留，工具仍经原 Broker 审批；普通文本动作不开放工具。模型、协议、思考、预算、语言和费率按运行冻结，编辑设置不改变在途任务。自定义兼容服务的推理参数声明默认关闭，并绑定准确服务。

原生中英文设置显示模型来源及有效值，动作编辑器固定保存／取消，长内容滚动；保存反馈在按钮旁，继续编辑会清除旧提示。CLI建议增加按准确任务进入审阅的入口，生成命令仍不自动执行。活动AI总结显式冻结界面语言，旧基线中发现的语言错误保留在验收记录中。

配置升级schema2并保留v1模型及覆盖；安装／回退检查签名配置reader，旧包不能覆盖新模型设置。新增桌面验收scope及存储基础层，独立桌面验收App和真实插入资格仍在建设中。

实际公开与安装状态以GitHub Release、manifest及App签名为准。仍为早期alpha：真实最新模型质量、完整明暗／IME／VoiceOver／多屏／物理快捷键、最低系统与长期驻留分别验收；当前已观察子集不代表全产品完成。支持与隐私请求：arthur.wang.wsx@gmail.com。
