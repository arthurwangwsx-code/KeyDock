# KeyDock 0.1.0-alpha.16

本版增加独立、可审阅的完整配置定义JSON导出。六类可选，覆盖命令、AI／Agent、工作流、常用工具、快捷键、桌面与调度定义；保留原ID／顺序，检查引用和预算，明确列出未选依赖与本机待补字段。

在设置 → 隐私与权限 → 导出配置定义中审阅后保存。钥匙串值、环境值、MCP秘密引用、授权、目录书签及历史不包含；提示词、片段、参数、URL和路径仍可能含私人内容，分享前须自行审阅。此文件并非匿名备份，目前尚不支持导入。

中英文审阅、后台冻结预览、同字节系统保存、取消／重试／关闭围栏已接通。工程与真实观察范围见[实现复查](../implementation/configuration-export-2026-11-25.md)。发行状态以GitHub Release和[状态总账](../status.md)为准。

完整产品仍为alpha，真实兼容API待用户配置；完整视觉／辅助功能、真实目标插入／窗口多屏及长期驻留验收未完成。支持与隐私请求：arthur.wang.wsx@gmail.com。
