# KeyDock v0.1.0-alpha.8

本轮完善界面语义、编辑隔离与工作流快捷运行流程。完整产品仍为PARTIAL；实际发行以GitHub Release与状态总账为准。

- 原生只读预览按实际UTF8同步规范等价正文，避免留下旧字节；正文相同时保留用户选区。
- Agent指令／任务、Workflow临时输入、AI提示词及剪贴板排除列表编辑器提供中英文辅助功能名称。
- 计划列表明确显示下一次执行时间及界面使用的时区，不改变保存的触发规则、审批和执行时刻。
- 启动台视觉与辅助功能共用结果副标题，保持用户正文和必要技术路径的原文。
- URL动作的运行选择与编辑草稿分离，避免选用A后新建B覆盖A；导航／切换语言保留草稿，删除目标拒绝旧草稿保存。写入失败和数量上限在当前工作区明确提示。
- 命令集合保留用户顺序，支持前后移动、显式移除与独立编辑草稿；AI入口打开空白手动输入页，CLI显示任务。浏览／编辑行身份分离，保存后收起候选。
- 剪贴板面板加强高对比选中态与实色阅读背景，合并重排的辅助名称包含位置；玻璃移到背景，修补材质切换导致搜索文本选区重置。隔离Preview提供进程内视觉样例，便于后续复查。
- AI服务未配置时主要动作引导设置；运行按钮和菜单共用配置检查，动作独立模型与CLI／Agent的全局模型分别判断。检查不读密钥、不联网，配置完成不会自动运行草稿。
- 工作流快捷入口按真实依赖收集初始文本；独立输入页保留原编辑稿，取消不运行，定义变化需重载审阅。固定流程保留一键运行，专用工作流快捷键跳过通用Launcher目标捕获。
- 应用目录的卷通知注册与清理进入后台生命周期，保留准备失败后的恢复通道及停止／重入围栏；减少启动台路径上的同步系统准备。

当前候选的原生OCR检查复发失败，尚未放行发行。正式发布状态以GitHub Release和状态总账为准。

实际VoiceOver、完整视觉、物理快捷键、真实AX／自动插入、最低系统和模型质量仍待验收。
