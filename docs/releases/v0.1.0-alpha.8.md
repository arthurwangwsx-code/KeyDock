# KeyDock v0.1.0-alpha.8

本轮修补界面语义与文本显示，完整产品仍为PARTIAL；实际发行以GitHub Release与状态总账为准。

- 原生只读预览按实际UTF8同步规范等价正文，避免留下旧字节；正文相同时保留用户选区。
- Agent指令／任务、Workflow临时输入、AI提示词及剪贴板排除列表编辑器提供中英文辅助功能名称。
- 计划列表明确显示下一次执行时间及界面使用的时区，不改变保存的触发规则、审批和执行时刻。
- 启动台视觉与辅助功能共用结果副标题，保持用户正文和必要技术路径的原文。
- URL动作的运行选择与编辑草稿分离，避免选用A后新建B覆盖A；导航／切换语言保留草稿，删除目标拒绝旧草稿保存。写入失败和数量上限在当前工作区明确提示。

这是界面修补，不代表实际VoiceOver、完整视觉、物理快捷键、真实AX／自动插入、最低系统或模型质量已验收。
