# KeyDock v0.1.0-alpha.2

第二个 macOS arm64 开源预览，修复真实原生交互发现的问题。整体日用验收仍为 PARTIAL。

## 本次改进

- AI运行与停止使用原生菜单快捷键：⌘Return运行当前草稿，⌘.取消当前任务；与按钮共享所有权、在途和退出检查，不执行隐藏窗口的草稿。
- 命令／AI动作设置使用原生新增工具栏按钮，保留未保存编辑；常规等页面移除空工具栏控件。
- 首次打开任务工作区会选择已恢复任务，再次打开保留原页面与选择。
- 用小型HTTP故障夹具验证Agent部分用量展示，保留独立的大响应总预算测试；超时诊断仅记录状态与数量。

## 本机验证与安装

已在解锁后的Mac上实际操作中文／英文与深浅色、草稿新建／恢复、命令保存和执行、输出进入AI、⌘Return流式请求、⌘.取消及只读Agent两轮工具调用。AI使用本地合成服务，无外部模型调用或API密钥；这些证据不代表真实模型质量验收。

本地流水线仅在Developer ID签名、App与DMG公证、装订、Gatekeeper和摘要校验通过后生成发行资产。下载DMG或ZIP安装到Applications；开发者使用 `make install` 正常退出旧进程、原子替换并保留可核验的回退凭据。源提交、版本和SHA-256以随包的release-manifest.json和SHA256SUMS.txt为准；alpha.1保留原标签和原资产。
