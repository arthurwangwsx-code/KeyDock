# KeyDock v0.1.0-alpha.23

继承全局／九类场景／动作和Agent独立模型、思考、输出预算及实际请求冻结。模型清单只在用户点击后刷新，推荐目录与服务返回ID独立，保留准确自定义ID及现有选择；当前服务的成功清单也可用于定义覆盖。

针对alpha.22本机清单刷新失败保留记录，JSON传输改为有界分块，避免大量短行占满SSE队列；SSE交付合同不变，仍拒绝尾块静默丢弃。错误仅展示鉴权／限流／超限／超时等固定类别，旧清单与选择保留；不输出服务正文、URL或密钥。15秒、1MiB、512ID和4MiB工作预算不放宽。

alpha.22为本地未公开候选，不覆盖其公证资产。翻译none已单独保存、正常重启并经真实翻译复验；早先仅凭界面作出的参数判断及用量加总已更正。仍为早期alpha，完整视觉、系统交互、所有质量样本与长期可靠性保持开放。支持与隐私请求：arthur.wang.wsx@gmail.com。
