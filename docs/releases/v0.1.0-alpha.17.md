# KeyDock 0.1.0-alpha.17

本版补齐工作流与MCP来源的移除审阅：列出调度、集合或Agent引用，解除后才能删除；在最终确认时重新检查，防止过期确认和旧编辑稿重新创建已删除对象。

工作流移除一并清理自己的快捷键、收藏、别名与最近项，在途工作流保留冻结快照。MCP移除暂停来源并取消调用，保留已导入文本、草稿、历史与存储密钥；保存失败会明确说明本会话暂停及重启风险。取消不承诺撤回外部已经完成的效果。

同时修补MCP迟到清理覆盖新目录、旧保存覆盖较新断开、旧回调清空新key等问题，并将配置异步操作接入退出等待。Agent失效来源／工具与历史孤儿工作流偏好提供显式修复。

工程与验收范围见[实现复查](../implementation/source-removal-2026-11-25.md)，实际发行状态见GitHub Releases与[状态总账](../status.md)。完整产品仍为alpha，真实API、完整视觉／辅助功能、多屏、最低系统及长期驻留未完成。支持与隐私请求：arthur.wang.wsx@gmail.com。
