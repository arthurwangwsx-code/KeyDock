# KeyDock v0.1.0-alpha.1

首个 macOS arm64 开源预览。完整源码采用 MIT，开发基线为 master；本地与 CI 共用工程脚本。

## 安装与更新

下载 DMG，将 KeyDock.app 拖入 Applications；或下载 ZIP 解压后移动到 Applications。资产的签名、公证、版本、源提交和 SHA-256 记录在 release-manifest.json 与 SHA256SUMS.txt；本地发布入口只在 Developer ID、Apple 公证与 Gatekeeper 校验通过后生成发行包。

开发者可使用 `make debug` 安装独立 KeyDock Preview；正式包使用 `make install`，替换前验证身份、请求旧进程正常退出并保留回退凭据。详细流程见 docs/technical/release-pipeline.md。

## 当前能力

- 独立启动台、设置和任务工作区；原生 Liquid Glass、英文／简体中文与跟随系统。
- 应用搜索／启动、窗口／选区适配、保存的 CLI、运行状态／输出／取消与元数据恢复。
- 可选纯文本剪贴板、可配置兼容 API、翻译／总结／命令解释、命令建议与只读 Agent 基础。
- 配置与凭据不随源码或安装包分发；剪贴板默认关闭，选区与窗口操作按需使用系统辅助功能权限。

## 验收范围

当前为 alpha，完整日用验收尚未完成。已有合成单测和部分真实窗口／双语／CLI操作证据；真实物理快捷键、IME、多屏／全屏、AX授权／撤销、Terminal交接、外部模型API与20条质量评阅仍有待完成项。macOS14是编译部署目标，最低系统和Intel尚未实测。CI预览包是隔离调试用途，与此正式身份的预发行包分开。

本轮曾观察到恢复／小窗口下工作区顶部裁切，已调整窗口尺寸管理、工具栏宿主和AI页滚动；最新原生检查工具连续超时，视觉修复尚未获得完整复验。请将此包用于早期试用和反馈。
