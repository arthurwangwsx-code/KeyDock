# KeyDock v0.1.0-alpha.4

这是原生macOS arm64的扩展能力alpha。启动台、独立设置、菜单栏入口及任务工作区继续分离，界面支持中英文；完整日用验收仍为PARTIAL。

## 新增能力

- 13项窗口布局、跨屏与按窗口身份恢复，写后读回确认。
- 可配置多步Agent、冻结命令／MCP工具、逐次审批、预算、暂停及显式新attempt；未知副作用不自动重放。
- 工作流编辑、输入输出连接、动态argv完整预览审批，以及App内interval／明确时区daily计划、durable claim和unknown人工检查。
- MCP HTTP／stdio两个显式协议版本，tools／resources／prompts；stdio启动发现与普通请求分别计时，旧配置兼容。
- 本地Vision OCR、单文件文本／PDF文本层与区域截图入口，结果先预览再选择AI动作。
- Snippets、选定目录文件名搜索／Finder显示、算式、单位换算、URL模板和命令集合。
- 默认关闭的工具内使用统计、聚合导出／清除及用户触发的AI总结。

## 发行资格

完整本机检查强制运行生产accurate OCR的独立进程与重复识别，绑定源SHA、测试清单、配置／图片／日志摘要、系统及工具链。App与schema2 manifest封入对应资格摘要，打包／重用／发布核对同源push core CI；后续未解决的完整检查失败会阻止使用历史PASS。

云端core与本机系统能力分别记录。GitHub VM的Vision诊断未获资格，标记为NOT_QUALIFIED；不将云端core通过描述为OCR通过。ZIP与DMG内部App核对源、版本、build、资格和整个bundle摘要；只读核验并正常卸载。`make install`消费当前已核验发行包，保留原子替换及回退receipt。

具体源提交、资格、系统、CI、公证和最终资产摘要见release-manifest.json。alpha.1／alpha.2原tag及资产保持不变；未公开的alpha.3候选保留在本地，未补造新资格。

## 验收边界

真实外部AI API按用户决定稍后配置，目前支持自定义兼容API。Accessibility／Screen Recording由用户手动授予；真实多屏、权限撤销、IME、辅助功能、最低系统、模型质量、长期性能与完整视觉矩阵尚未全部验收。Terminal GUI仍未验收。

外部stdio进程并非OS沙箱；仅处理文本上下文，不声称图片多模态、ACP／PTY、不可信扩展隔离、后台daemon调度、整机追踪或自动更新器已经实现。计划仅在App打开时运行。个人配置、bookmark、凭据、截图、剪贴板、正文与本机日志不随公开资产上传。
