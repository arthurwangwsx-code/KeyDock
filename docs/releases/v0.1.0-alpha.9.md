# KeyDock 0.1.0-alpha.9

本版本接通多应用桌面工作区执行；工程资格、公开资产与真实系统验收分别记录，精确源码及发布状态以GitHub Release和状态总账为准。

- 桌面工作区接通组合执行：设置应用、Launcher和独立快捷键共享同一入口，可依次准备应用、聚焦原冻结窗口并应用保存的布局与屏幕策略。
- 全部已有窗口先预检，再按明确策略后台准备缺失应用；每项布局前统一复核身份／窗口／屏幕，不创建新窗口或自动改绑。
- 分阶段结果区分已确认、未派发与已提交未确认。取消／新入口／定义变更会停止后续步骤并等待已提交操作收口；不承诺桌面原子回滚。
- 父子回执保留有序结果，重启后不重放；缺少记录显示无法确认。回执保存失败不会抹掉已知步骤，界面提示核对后再运行。
- 清空别名会真正移除引用，写入失败保留原设置；修补清空后仍无法删除工作区的问题。
- 直接工作区快捷键不会读取选区；失效目标在设置页报告。设置和结果页支持中英文、玻璃／实色与既有对比度偏好。

当前Mac的真实辅助功能、多屏、物理快捷键和完整视觉矩阵仍待验收。自定义兼容AI API仍由用户稍后配置，未代用户复用密钥或产生付费请求。alpha阶段未承诺最低系统、Intel或日用完整资格；本版本为arm64 macOS构建。
