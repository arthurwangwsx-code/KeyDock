# KeyDock v0.1.0-alpha.3

这是尚未公开的扩展能力候选，macOS arm64；完整日用验收仍为PARTIAL。本地签名公证已通过，远端OCR门禁未通过，尚未安装或发布。该版本继续使用原生启动台、独立设置／工作区和中英文界面。

## 新增能力

- 窗口半屏／四角／最大化／居中／跨屏／恢复命令与快捷键入口；按窗口身份保存原始位置，写后读回确认。
- 可配置的多步Agent：保存命令／MCP工具选择、逐次审批、工具与输出预算、暂停／取消／显式新attempt；未知副作用不自动重试。
- 可编辑工作流：保存命令、AI动作、文本变换和手动输入，支持前一步输出；动态argv绑定执行前展示完整参数并审批。
- MCP HTTP／stdio来源管理，显式2026-07-28／2025-11-25协议版本，工具目录、resources／prompts文本预览；stdio来源需要用户信任。
- 本地Vision图片OCR、单文件UTF-8／PDF文本层导入、用户触发的区域截图；结果先预览再选择AI动作。
- Snippets、选定目录的文件名搜索／Finder显示、算式与单位换算、URL模板动作和命令集合。
- 默认关闭的工具内使用统计、聚合导出／清除和用户触发的AI总结。
- App运行期间的interval／明确时区daily计划；durable claim、授权指纹、配置改变暂停与unknown人工检查。
- 单App数据目录owner，父子回执保护，真实子进程回收后再释放运行容量。构建流水线限制并发，继续保留签名公证、安装回退和资产回下载检查。

## 验证与边界

本机统一检查382项Swift、34项Python及503条中英文UI key通过，包含真实owned子进程取消／回收、本地合成Vision OCR、loopback模型／MCP、工作流冻结／审批／字面参数、调度落盘失败与目录身份变更回归。Terminal生命周期独立强制验证，保留两秒断言和全部用例，避免其他并发合成夹具污染时间测量。发行继续经过同一流水线和精确源SHA检查；资产中的release-manifest记录实际版本、源提交、签名、公证及摘要。

外部AI服务按用户决定稍后自行配置，当前支持自定义兼容API；本轮未使用真实密钥或个人数据进行模型质量验收。Accessibility／Screen Recording由用户在macOS中手动授予，真实窗口布局、多屏、权限撤销、IME、辅助功能与完整视觉矩阵尚未全部验收。普通CLI交接的Terminal GUI仍未验收。

MCP目录与审批不是OS沙箱，外部进程仍具有当前用户权限。仅处理文本上下文，不声称图片多模态发送、ACP、PTY、任意不可信扩展隔离、后台daemon调度、自动更新器或整机活动追踪已经实现。计划只在App打开时运行；unknown不会自动重放。

现有alpha.1／alpha.2的tag与资产保持原字节。个人配置、bookmark、凭据、截图、剪贴板、正文、构建日志与签名材料均不随源码或Release上传。正式包替换可通过工程脚本执行并保留回退receipt。
