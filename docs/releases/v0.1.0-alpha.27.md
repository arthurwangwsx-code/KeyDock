# KeyDock 0.1.0-alpha.27

修复清除AI用量后，尚未发布的旧任务回执快照把已清数字重新带回界面的问题。启动恢复与任务清理的失败组共用读前票据；任务、阈值和恢复身份保留，失效的消耗与剩余额度显示未知。

AI与Workflow的历史用量读取也拒绝清除中创建的工作，清除后取得的新鲜读取仍可显示新事实。修补不更改在途Agent额度、不恢复旧授权或自动执行任务，也不要求重新配置模型或密钥。

完整产品仍处于alpha验收阶段。自动维护预算副本、费用停止阈值、完整玻璃／系统矩阵、真实目标插入和实体热键等义务继续开放。此增量使用owned合成回执与loopback验证，真实外部模型资格按原始版本独立记录。

交付和验收事实见[实施记录](https://github.com/arthurwangwsx-code/KeyDock/blob/master/docs/implementation/usage-restoration-fence-2026-11-26.md)。技术支持、反馈和隐私请求：arthur.wang.wsx@gmail.com。
