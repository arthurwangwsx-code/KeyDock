# KeyDock v0.1.0-alpha.22

AI服务新增“刷新模型清单”，可将服务返回的准确ID加入全局与场景选择。当前保存服务的成功清单也用于动作和Agent覆盖。官方最新推荐目录独立维护；刷新不替换当前选择，不将返回ID当作思考、工具或价格证明。未知或清单中缺失的选择仍可手工填写。

刷新仅由用户点击发起；取消、关窗口、换服务或改凭据后拒绝迟到结果。草稿密钥绑定输入时的端点，改地址清空。请求不跟随重定向，有总时间／正文／数量上限，实际网络收口后才释放预算；HTTP队列满时连最后不足一块的数据也明确失败，避免静默截断。

继承alpha.21的默认／九场景／定义模型设置、Responses多轮工具和签名配置reader门禁。仍为早期alpha，完整系统交互、视觉、模型质量和长期驻留未全部验收；真实发布／安装状态以Release及签名manifest为准。支持与隐私请求：arthur.wang.wsx@gmail.com。
