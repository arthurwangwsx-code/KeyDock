# KeyDock 0.1.0-alpha.19

本版增加显式“准备新尝试”：已保存的CLI、AI动作、Agent及Workflow记录可重新审阅当前定义、工具范围和预算，提供新的空白输入后开始独立任务。旧结果与费用保留；中断／未知结果需要明确确认，不自动重跑。没有定义引用的旧历史仍仅供查看。

新AI尝试默认只展示，不自动复制或替换选区。MCP重新发现后核对选中工具合同，配置变化、写入失败或来源不可用会阻止派发。准备页支持中英文及明暗外观，长范围滚动，底部操作固定；任务详情和状态语言更新已修补。

统一安装／回退流程增加签名能力声明和数据格式检查。新任务元数据采用Envelope v2，旧alpha.18仅读v1：一旦产生v2记录，统一工具会拒绝不兼容的二进制回退，并保留App和数据。尚无跨版本数据降级／archive恢复；请勿用旧脚本或手工拖拽覆盖来绕过门禁。

原生合成调试增加`native-review`流水线入口和独立owned数据目录，可复用同一fixture做重启验收。真实兼容API仍待用户配置；物理热键／自动插入、AX／多屏、完整视觉与辅助功能、最低系统和长期稳定性尚未全量验收。完整产品及完整RunStore仍为PARTIAL。
