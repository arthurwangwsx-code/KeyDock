# KeyDock v0.1.0-alpha.6

本版扩展窗口与应用控制，增加独立应用动作设置、直接快捷键派发和更明确的执行回执。Launcher、剪贴板面板、Settings与Workspace继续分离，并支持中英文。完整产品验收仍为PARTIAL。

- 应用可创建多个命名动作，配置启动／激活、前台隐藏否则显示、隐藏、显示、将所有窗口置前和正常退出，再分别设置别名、收藏与快捷键。配置独立存储，旧版保存基础设置不会丢弃新动作。
- 窗口管理分类增加当前应用的上一／下一窗口与当前窗口最小化，连同原有13项布局直接绑定。循环保留稳定顺序，并在真实焦点确认后推进；AX权限、目标实例和取消在每步核对。
- 桌面动作先保存最小intent，区分状态确认、已请求、拒绝和未知。正常退出只请求一次，保留应用自己的保存流程；重启不重放。用户打开新入口或改变动作时，旧准备请求不能迟到抢回焦点。
- 修复首次编辑未载入保存值、显示步骤提前短路、部分变化误报失败，以及恢复历史时丢失请求说明的问题。新增普通「显示／View」菜单，设置和工作区可以直接返回快捷入口。
- 工程入口增加合成原生宿主及磁盘空间预检，继续使用本地构建、公证、原子安装／回退与GitHub资产回下载流程。

隔离Preview已实际检查中文浅色／英文深色、新建／首次编辑／校验、快捷键保存与别名查询。合成应用的隐藏→显示、拒绝退出时只收到一次请求、另一次明确允许后的正常退出已观察。物理全局热键、实际AX窗口循环／多屏／Spaces、真实保存对话框、最低系统与完整视觉／辅助功能矩阵仍待验收。AI模型质量和第三方服务仍需用户配置真实API后验证；新增桌面动作没有自动进入模型工具白名单。

发行仍要求当前干净源码的完整本机资格、同源core CI、Developer ID／App与DMG公证、内部App一致性与公开回下载。云端系统OCR为NOT_QUALIFIED。实际源、资格、CI、签名及摘要以manifest和状态总账为准；旧版tag和资产保持不变。
