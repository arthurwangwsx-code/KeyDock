# KeyDock 0.1.0-alpha.26

启动台随搜索结果数量调整高度，保持顶部位置和输入焦点；稀疏结果减少空白，大量结果保留滚动。AI紧凑面板沿用独立布局，通知与底部操作保持有界。

修复中英文切换后用量卡和未命名草稿菜单仍显示旧语言的问题。CLI建议与只读Agent入口显示其实际场景模型。工具栏按当前操作收紧，AI内容区支持滚动。

Agent审批显示冻结的命令名称，同时保留协议标识与准确参数。在等待期间改名不会更改已经请求的操作；仍需逐次明确确认。

完整产品继续处于alpha验收阶段。实体热键、真实目标插入、IME／VoiceOver、多屏、最低系统、长期驻留及完整玻璃视觉矩阵保持开放。费用停止阈值、完整持久步骤与原图附件仍待后续实现。本轮UI探针使用合成loopback输入；已有真实OpenAI资格按各原始版本记录。

发行和验收事实见[实施记录](https://github.com/arthurwangwsx-code/KeyDock/blob/master/docs/implementation/native-ui-clarity-2026-11-26.md)。技术支持、反馈和隐私请求：arthur.wang.wsx@gmail.com。
