# KeyDock v0.1.0-alpha.5

本版增加独立剪贴板快捷面板和更易发现的快捷键定制，继续保持原生Launcher、Settings与Workspace分离及中英文界面。完整产品验收仍为PARTIAL。

- 剪贴板历史可从启动台、菜单栏或配置的全局快捷键进入。搜索、↑↓、完整预览、固定／删除、⌘Return复制和Return请求插入形成独立流程。
- 插入前冻结原应用／窗口／文本位置，验证权限与焦点；查询或选择变化、取消、第三方应用激活、剪贴板竞争会拒绝旧请求。所选纯文本保留于剪贴板，不读取或自动恢复旧正文，不重试已发送事件。
- 新增快捷键动作分类，直接配置13项窗口布局、应用、AI、命令及工具；剪贴板有专用绑定和别名入口。现有配置不会被自动添加新的全局绑定。
- 修复首次搜索焦点、窗口标题语言同步和深色正文阅读层；系统玻璃外壳保留可读的选中态与正文层次。

原生Preview已观察中文浅色／英文深色、查询选择、复制入口及快捷键保存。真实插入、物理热键、权限／多屏／IME／辅助功能及完整视觉矩阵仍待验收；事件发送不证明接收方已经消费或保存。真实AI接口按用户决定稍后配置；本版不将合成检查替代真实模型质量。

发行仍要求同源完整本机资格、指定core CI、Developer ID／App与DMG公证、ZIP与DMG内部App一致性及公开回下载。云端系统OCR为NOT_QUALIFIED。具体源、资格、CI、公证及摘要见manifest；旧版tag／资产保持原字节。
