# KeyDock 0.1.0-alpha.12

本版本包含以下增量。实际公开、安装和验证状态见项目状态总账与GitHub Release。

- MCP工具schema支持标准annotations和开放／受限额外属性，保留原声明；默认值不自动填参，外部只读提示不授予权限，未知约束仍拒绝。
- 现代协议接受任意有界JSON结构化结果；旧协议保持对象合同，服务端工具错误独立保留。
- legacy HTTP按原请求ID取消，断开时清理已知会话；取消初始化不发送禁止的通知，刷新期间断开不会重新连回。
- 清理使用精确原来源的短期认证快照；撤权后不重新读取凭据。超时、405或未知结果明确计数，不覆盖原请求错误或自动重试工具。
- 增加固定官方Time服务、官方SDK慢任务及两协议／两传输的工程验证入口，依赖和安装树逐字节核对；提供独立手动CI工作流。

Time互通仅覆盖时间工具；SDK慢任务是自有夹具，不等于全部第三方兼容或实际远端副作用撤回。真实外部AI按用户决定稍后配置。完整视觉、真实IME／VoiceOver、权限下跨应用插入／窗口控制、多屏和长期性能仍需独立验收。技术支持与隐私请求：arthur.wang.wsx@gmail.com。
