# KeyDock 0.1.0-alpha.25

Agent支持可选的整次任务已报告token阈值。每轮核实完整输入／输出用量后再调用工具；到线或无法核实用量时暂停，保留已经返回的结果。后续请求的输出上限会收紧到剩余阈值。内建只读Agent固定使用32000阈值，自定义Agent可以开关和设置。

配置、任务详情和工具审批均显示本次固定限制，支持中英文。运行期间修改配置只影响新任务；取消／暂停后迟到审批不能继续执行。清除AI用量历史会同时擦除已结束任务摘要中的计数，在途限制继续有效。

配置schema4和任务回执Envelope3分别保护新增字段；旧版本的安装／回退会在不兼容时拒绝，保留当前数据。完整配置导出的定义部分升级为v2，明确记录关闭状态。

阈值依赖服务返回的用量，单次请求可能先超出它，不能保证账单硬上限。费用停止阈值、持久步骤记录、原图附件、真实插入／实体热键和完整系统／视觉矩阵仍开放。真实OpenAI模型资格按各源独立记录；本增量在正式App另验证时间工具两轮450输入／40输出、预算摘要490。1062项Swift执行、156项流水线测试和中英文原生子集通过，不替代完整模型质量／系统验收。

发行与验收事实见[实施记录](https://github.com/arthurwangwsx-code/KeyDock/blob/master/docs/implementation/agent-run-token-budget-2026-11-26.md)。技术支持、反馈和隐私请求：arthur.wang.wsx@gmail.com。
