# KeyDock 0.1.0-alpha.18

新增可选的自定义AI费率、逐次请求用量快照及本地历史分析。费率按准确API服务和请求模型匹配，运行开始后冻结；修改或删除费率不会重算已有历史。金额按原币分别估算，缺失的费率／用量保持未知，不代表服务商账单。

工作流父任务只引用AI子请求，避免历史合计重复。使用分析提供独立7／30／90天AI用量区，与可选动作统计和其AI总结输入分开；清除、过期、损坏或缺报均保留覆盖提示。费率编辑、单次与历史展示提供中英文。

个人Mac工程入口增加完整流水线的共享存储准入与嵌套租约核验；其他开发环境保持可用。发行、安装与回退继续复用既有签名／公证／GitHub流水线。

这是alpha版本，已签名公证并公开发布；本地安装实际About为0.1.0-alpha.18 (18)。[当前状态](https://github.com/arthurwangwsx-code/KeyDock/blob/master/docs/status.md)及[发行证据](https://github.com/arthurwangwsx-code/KeyDock/blob/master/docs/implementation/alpha18-release-2026-11-25.md)分别记录已通过范围。真实兼容API与账单对账、模型质量、完整视觉、目标插入／AX、多屏、输入法／VoiceOver、最低系统和长期驻留仍有独立验收义务。
