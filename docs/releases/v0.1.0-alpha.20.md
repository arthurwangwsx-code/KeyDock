# KeyDock v0.1.0-alpha.20

实际公开状态与精确资产以GitHub Release、发行manifest及App签名为准。

本版本增加可选任务内容保留。默认关闭；开启后可为后续AI／Agent／Workflow捕获准确运行输入，在任务页逐项审阅保存原输入、可见结果或最近成功步骤。CLI不把参数／环境变量当作独立输入，Agent结果包含工具返回并明确提示。保存不是自动归档，也不恢复执行权限。

“已保存内容”独立于普通任务列表，重启只列元数据，打开后才读取正文。可将保留原输入明确填入新尝试；已有输入先预览并确认替换，仍需审阅当前范围并点击开始。删除、清除历史、关闭捕获和部分失败有独立状态及过期请求保护。

任务结果、AI输出与执行范围预览共用原生只读文本组件，较长正文独立滚动。紧凑AI面板将正文与固定动作区分开，超限／失败提示和工作区入口保持可达。

启动台关闭草稿先呈现审阅，取消保留当前内容；确认后等待该草稿的请求收口。确认框实际关闭前，启动台快捷键不会再次运行背后的草稿。

内容在本机私有文件中保存，不提供应用级加密；7天后到期并拒绝读取，文件在下次应用维护时清理。最多200份／64MiB、单文件编码后4MiB；不会自动发送历史文本给模型，也不会将正文写入配置导出或诊断。停用释放临时内容，已有保存仍可查看／删除。安装／回退会检查签名reader能力，旧版遇到保留内容或未完成清除时拒绝回退。

发行候选同时包含冻结打包输入、独立inode消费、公证ID持久续查与unknown不自动重投的新流水线；真实新协议完整提交／发布的结果另记，不能用alpha.19历史恢复替代。

仍为早期alpha：暂定最低macOS14，当前主要资格环境为macOS27.2 arm64。完整视觉／辅助功能／IME／全屏多屏／物理快捷键、长期驻留及真实外部AI质量仍待验收；真实API按用户决定稍后配置。支持与隐私请求：arthur.wang.wsx@gmail.com。
