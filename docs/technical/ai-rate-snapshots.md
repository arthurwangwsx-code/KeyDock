# 可选AI费率与调用快照

2026-11-25，任务32计划，尚未实现。承接4.7及独立用量分析，不以本方案或alpha.17交付关闭这些原始验收义务。

## 用户闭环

AI服务设置提供独立费率区，按精确服务endpoint身份及实际请求模型名配置币种、每百万输入／输出token的十进制单价、启用及移除；空缺保持未配置，零须明确填写。费率不参与API结构就绪判断，不读Keychain、不联网，不自动下载价格或换汇。模型override独立匹配，同host的不同path／query不得串价。配置补偿失败保留原文件与编辑稿，定义可随完整配置导出，但用量账本不导出。

运行准备时冻结服务、模型和可用费率配置集；同一Agent／Workflow已启动后改价或删价不改变其后续调用的依据。每个实际transport.open之前再创建独立attemptID并绑定已冻结的准确费率、开始状态，decoder使用同一身份。发送前被校验／取消拒绝不产生已发送调用；每次重试和Agent轮次是新attempt，不按responseID跨调用去重。

| 情况 | 展示合同 |
|---|---|
| 未配置费率、无可用计数、旧记录无历史快照 | 费用未知及原因，不套用当前价格 |
| 所需计数与费率完整 | 按已报告用量及自定义费率估算，显示原币 |
| 失败／取消、缺失字段或轮次 | 已报告部分的估算，其余未知；保留已有事实 |
| 显式零token或零费率 | 只有依据充分时可展示估算零 |
| 计数或金额溢出／坏快照 | 费用未知，不钳为零；有效token事实独立保留 |

费用与usage完整性分开。采用有界Decimal／精确十进制运算和检查溢出，只在显示边界舍入，极小正值不能冒充零。以累计快照合并结果计价，重复SSE usage不重复相加；继续明确拒绝不具稳定身份的delta并标未知。本增量仅统一输入／输出费率，不猜测缓存折扣或服务商额外项目，不称账单、已扣费或费用下限。

## 架构与归因

AICore承载纯费率值／匹配／计算和provider逐请求身份，WorkbenchFeature承载设置、冻结、持久化与共用展示，继续复用AIUsageAccumulator及AIUsageMetadataStore。provider边界使用有界元数据记录端口，不能仅依赖UI流消费：消费者取消检查可能跳过已排队的started／usage事件。模型请求终态与产品终态分别记录，解析命令建议JSON、复制或写产品回执失败不撤销已报告用量。

普通AI动作、命令建议、只读及多步Agent、聚合报告AI总结均接通。Workflow按实际AI子调用记录parentRunID及步骤身份；父任务汇总只引用子调用，不新建可重复入总计的账项。手动／计划均在实际启动时冻结；尚未运行的计划不保存价格授权或伪请求。CLI／MCP服务内部模型消耗不属于本账本覆盖。

扩展版本化UsageReceipt保存逐调用元数据、可选费率依据、报告计数与完整性；旧格式兼容为无历史快照。新增字段不含提示词、正文、工具参数、完整endpoint或query，只保存准确服务指纹、模型／币种等必要有界字段。不另建第二个任务库或无界日志，继续64KiB单条／90天／数量和总字节预算。写失败可见，不能宣称账本完整；清除／TTL使金额、分析缓存和迟到恢复失效。

使用分析增加独立AI用量区，按7／30／90天展示可计价小计、缺报／无费率记录数和覆盖范围，币种分别汇总。读取有界usage元数据，不能仅sum(tasks)：工作流叶子与父任务、任务保留数量和用量保留数量不同。与默认关闭的动作行为统计、其清除及AI总结的输入选择分域，不自动把费用历史送模型。

AiBox只读参考ModelRateSnapshot／CostBasis、UsageReporting的wire-model与费率捕获、UsageAttribution父子归因；未迁源码、配置、历史价目或凭据。其缓存缺省比例、默认汇率及异常金额钳零不进入本合同。

## 验收与交付

必须验证：准确endpoint／override隔离；显式零与未知；累计重复／冲突／回退及Agent多轮缺报；发送前拒绝与发送后取消；在途改价／删价与重启保持快照；Workflow多模型／多币种归因不重复；十进制边界；旧文件／坏费率保留token；保存补偿；清除／TTL／迟到与写失败；敏感哨兵不落盘。原生中英明暗设置、单次结果及历史展示、同源完整检查和发行流水线分别记录。合成／loopback通过不能声称真实账单对账或模型质量通过。
