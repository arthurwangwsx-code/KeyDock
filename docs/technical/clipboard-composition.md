# 有序剪贴板合并

本增量继续任务10.7。实现位于`feature/clipboard-composition`，从已发行alpha.6后的master创建；正式安装包仍是alpha.6。完整工程、原生交互和发行资格分别记录，不能将本方案视为已验收。

## 交互

面板保留搜索游标与独立勾选清单。点击圆形选择按钮或在搜索框按Shift-Return加入／移出当前条目，新增项追加末尾；搜索、固定导致的列表重排和悬停不改变清单顺序。右侧显示编号、前移／后移／移除和一份完整合并预览。没有勾选项时继续操作当前单项；有勾选项时只操作编号清单，即使查询没有结果也不悄悄回退到另一条目。

最多20项，合并后的UTF8正文连同分隔符最多1MiB；默认换行，也可选空行、空格或无分隔符。超过预算拒绝整批，不截断、不并行派发。合并正文只保留在本次面板内存中，不进入偏好、回执、普通日志或模型输入。

设置→剪贴板提供Return主动作和分隔符。Command-Return执行另一动作，底栏显示对应键位；原生运行菜单复用同一替代动作解析。两项无正文的偏好独立写入当前App的UserDefaults域，旧版重写configuration.json不丢弃它们；Preview使用独立bundle域。它们是界面偏好，不授予权限或开启记录，UserDefaults不提供文件事务／掉电持久性保证。

## 数据与执行

纯模型`ClipboardComposition`校验ID、唯一性、数量和字节预算，逐项向读取端提供剩余预算，避免先加载20份大正文再检查。Store的composition在一个SQLite事务内按同一时刻清理过期项、保序读取、在解码前检查列字节数；缺一项即整批失败。不会在MainActor循环await单项读取，也不在查询列表保存整库正文。

面板的合并generation独立于搜索游标；清单、顺序、分隔符、刷新、关闭和重开撤销旧预览。提交另有generation及单次in-flight限制。提交时重新批量读取并比较完整快照；若与已展示正文不同，只更新预览并要求再次主动提交。缺失或超预算时保留清单与错误，不能默默复制剩余项。

复制只提交一次纯文本写入，通过同一事务stage检查writeObjects、changeCount和私有nonce，不读取旧正文。写入失败回传面板，保持可查看内容；剪贴板可能已被部分改变，不承诺旧正文回滚。历史选择／插入写入瞬态类型阻止自采集；普通AI结果、Snippet等复制保持普通类型，仍可供后续用户明确触发的剪贴板输入使用，不放宽对外部concealed／transient的过滤。

所有复制入口都获得抛错路径，注入的旧writer仍覆盖普通与历史复制，避免测试或隔离宿主意外使用系统剪贴板。AI自动复制失败独立提示交付未确认；完整生成正文、模型成功事实、usage及调用回执保持成功，不误导用户检查API或自动重跑模型。

插入将合并文本作为一次输入传给既有ClipboardPasteTransaction，沿用原进程／窗口／焦点／选区、权限、Secure Input、nonce、激活围栏和取消检查。只发送一次Cmd-V请求，不逐项并发按键；事件已发出不证明外部应用消费或保存。没有自动重试、恢复旧剪贴板或重启重放。

## 证明义务

定向回归覆盖UTF8与分隔符预算、缺失／过期、保序读取、跨查询清单、重排、正文变化要求重新查看、重复提交、偏好变更撤销和复制失败。必须另行观察中英深浅色、焦点与Shift-Return／IME、合成原生目标中的一次实际插入、权限撤销和不支持目标。个人历史、权限设置和真实API不得作为合成开发数据。
