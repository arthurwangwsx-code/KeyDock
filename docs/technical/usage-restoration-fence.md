# 用量清除与恢复读取围栏

状态：42.1–42.3开发实现；最终完整检查、原生及发行资格另行记录。自动维护的预算副本仍属42.4，不以本切片替代。

任务回执保存的数字与独立用量账本都会参与显示。清除时磁盘已清空，不代表调用者手里的旧list快照也已清空。启动恢复、任务清理失败组恢复必须在读取两库之前取得同一个用量票据，发布时验证它。

票据只存在于当前进程，包含所属fence的随机身份、usage代次和读取开始时是否允许恢复数值。清除中创建的票据始终无效；同代次在清除结束后也不重新授予资格。票据不持久化、不携带工具权限，也不修改现有配置或回执版本。

失效或缺失票据仍恢复任务标题、终态、阈值和runAttempt图；预算的knownTokens清为nil、completedTurns为0、状态为usageUnavailable，剩余额度自然未知。恢复不能以发布时的新票据重新包装旧数据。CLI回执当前不投影这些预算字段，保持其现有路径。

独立ledger／workflow读取在创建异步Task之前捕获票据，随后继续验证任务历史代次、usage代次、metadata revision和逐run失效状态。无关账本写入仍可按既有上限重读，不放松删除围栏。真实worker发布新事实不消费历史读取票据，不改变在途meter或旧执行授权。

证明分别覆盖：缓存旧预算晚于真实清除发布；清除中票据直到结束也无效；无票据／跨实例票据；清除后的新记录可恢复；真实任务清理内部旧快照与用量清除交错且AI删除EIO，只恢复未知数字、保持CAS与磁盘字节。正常启动的正向恢复仍由现有Agent预算重启集成测试覆盖；本切片不冒称已捕获真实GUI启动竞态。
