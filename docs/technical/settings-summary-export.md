# 设置摘要导出

此增量实现本地可审阅的脱敏设置摘要，不是恢复备份。完整别名／AI动作／其他定义的迁移导出继续保留为后续义务，不能由摘要关闭。

## 字段与快照

采用独立Encodable DTO白名单，不先序列化完整AppConfiguration再删字段。默认仅基础偏好：已知语言／外观枚举、剪贴板及Activity开关、剪贴板面板主动作和分隔符。可选启动器快捷键的启用状态／有界keyCode／已知modifier，以及主配置数量（含内置定义）。未知枚举输出固定unknown；非法热键仅输出invalid，不原样转出。

从已加载值生成，不读凭据、文件、网络或额外模块存储。任何自定义名称、ID、别名、提示词、片段、argv、路径、bookmark、服务连接、凭据、历史和使用明细均不进入摘要。所选快捷键与数量仍是用户设置，不宣称匿名。固定format／schemaVersion=1，编码后64KiB上限，超限或空选择整次拒绝，无截断。

JSON预览与系统保存面板使用同一份不可变Data。选择变化使旧预览不可保存，显式刷新才生成新快照；设置在别处变化不偷偷重建已审核字节。文件名固定KeyDock-settings-summary，不含用户数据。

## 呈现与保存

SettingsSession拥有稳定审阅呈现，每份快照和每次保存另有UUID；同一时刻仅一个保存尝试。保存中禁用刷新／选项／再次保存及审阅关闭。系统先收起面板再回调不能被当作取消：使用macOS14起的onCompletion／onCancellation独立回调，按呈现与attempt身份收口。

取消安静返回原审阅；失败保留候选并显示本地化错误；成功显示已保存且保留可查看的快照。关闭设置窗口或shutdown撤销审阅并释放快照，旧回调不得污染新呈现。已交给系统的写入可能完成，关闭窗口不承诺撤销该文件写入。

导出与命令／AI编辑、删除、遗留偏好修复、桌面工作区编辑双向互斥。待审命令在所有模态门禁通过后才消费。摘要不修改配置、注册热键或建立执行授权。

验证覆盖精确字段白名单、所有排除字段敏感哨兵、可选类别／非法值、字节上限、快照冻结、取消／失败／重试／迟到回调和关闭清理；原生中英明暗完成预览及系统保存。真实个人配置不作开发数据。
