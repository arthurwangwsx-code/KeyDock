# 数据、权限与执行策略

状态：设计要求，非已实现保证。用户设置、OS TCC 和模型工具授权是不同层；某一层同意不会自动放开其他层。日常保存动作在其配置范围内执行，不设计每次都重复弹窗。

## 权限地图

| 能力 | OS/应用边界 | 拒绝后的行为 |
|---|---|---|
| 搜索/启动应用 | NSWorkspace、允许位置索引；不默认全盘读取 | 仍可搜索内置命令，报告不可访问路径 |
| 全局快捷键 | 优先系统注册式 API；不为简单唤起收集全局键盘流 | 可从菜单栏唤起/重新录制冲突组合 |
| 窗口标题/切换/布局 | Accessibility，逐动作检查是否支持 AX 属性 | 无权限时保留应用级启动，窗口操作显示原因 |
| 选区读取/替换/自动粘贴 | AX、目标能力；Apple Events adapter 另需 Automation | 允许手动复制输入和只复制结果 |
| 截图/缩略图/屏幕理解 | Screen Recording，用户触发；音频独立 | 纯窗口标题搜索继续可用 |
| 文件/目录 | 用户选择路径，OS 文件权限；sandbox 模式需 security-scoped 处理 | 不自动申请 Full Disk Access |
| 外部 API | 明确 endpoint/model/data scope，key 在 Keychain | 未配置/离线时本地工具继续运行 |
| 登录项 | SMAppService，用户启用 | 未启用时手动启动，不重写系统设置 |

依据：[Apple Accessibility](https://support.apple.com/guide/mac-help/mh43185/mac)、[屏幕与音频录制权限](https://support.apple.com/guide/mac-help/mchld6aa7d23/mac)、[App Sandbox](https://developer.apple.com/documentation/xcode/configuring-the-macos-app-sandbox)、[SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice)。API 与实际 TCC 行为需在支持系统实测，不将某平台的权限名字硬套所有版本。

## 上下文授权

每次 AIAction/AgentRun 有 ContextEnvelope：输入种类、来源、采集时间、目标身份、范围与用途。首次配置可选择固定范围，如“只发送当前选区给指定模型”；快捷键使用该范围，无需重复确认。新增附件、整页/整屏、历史记录或不同 endpoint 时更新范围并显示变化。无输入时不自动扩大范围。

窗口标题、文件名、选区、网页/OCR 和工具返回都可能含敏感或恶意内容。模型对这些内容的推断不能授予权限；写文件、执行命令、替换文本、发送/发布与付费动作由独立执行策略决定。替换/运行预览提供真实目标和参数，不使用含糊“允许一切”默认值。

## 采集与保留默认值（待 P1 实测调优）

| 数据 | 默认与范围 | 删除/导出 |
|---|---|---|
| 配置、别名、AIAction | 本地持久保存，schema version；不含 key | 可导出脱敏配置 |
| 凭据 | Keychain，按 provider/endpoint 隔离 | 删除 provider 时可一并清除 |
| 剪贴板 | 默认关闭，启用后仅纯文本；24 小时/500 条，单条 1 MiB，总正文 32 MiB；逐出旧非固定项以接纳新项 | 单条/全部清除；固定项计入容量，无法共同容纳新项时拒收并提示，不删除旧历史 |
| 本工具 Activity | 用户启用后保留 30 天最小事件，不记录查询原文/标题/正文 | 停用、清空与导出聚合 |
| token/cost ledger | 仅元数据，无请求正文；90 天目标与清除待 P1 实现 | 按时间范围导出属后续；P1 清除待实现 |
| AI 正文与结果 | P1 仅会话内存；重启只恢复最小元数据，主动保存正文属后续 | 会话总量与草稿清除待实现 |
| 运行输出、Agent 恢复 | 当前单次输出有界；会话总预算与终态回执 TTL 待实现 | 删除任务联动清理待实现，附件属后续 |
| 截图/OCR | 用户触发，默认临时输入，发送前可检查 | 取消/删除后清临时文件 |

P1 剪贴板已使用 SQLite、事务和迁移版本；key 不入 DB。应用支持目录限制文件访问权限，用户可用系统磁盘加密；首版不承诺已实现应用层全库加密。AI/任务历史若启用存储，搜索索引/附件/缓存和导出都纳入清除。SSD/APFS 上逻辑删除不等于物理不可恢复，不能宣传安全擦除。

剪贴板先查类型标记，再读正文；跳过 concealed、transient 等约定类型与已配置密码管理器排除项。不同 App 未必标记敏感文本，不能保证识别所有秘密。前台 App 仅是来源提示，不是可靠写入者身份。睡眠/锁屏后不进行补采历史，清除时不记录原文。

当前保留治理缺口和下一步固定预算见[会话保留方案](session-retention.md)，其中的默认值尚未落地。

## 工具与第三方进程

Broker 策略有 deny、ask、allow-with-scope；scope 绑定调用者、工具版本、目标资源和有效期，可撤销。原生 adapter 负责在访问前和写入前复核资源与目标，不以模型自报风险替代校验。副作用重试遵循独立回执。

MCP server、外部 CLI、Node/Swift 扩展可直接使用其进程的真实文件/网络权限。清单、工具参数检查和子进程启动不构成安全沙箱。未实现 OS 隔离时只运行用户信任并主动启用的来源；文档和 UI 如实说明。采用真实沙箱前需验证文件、网络、子进程和凭证边界，不能仅做字符串扫描。

## 网络与诊断

API配置保存先快照目标endpoint的凭据槽和原配置文件，再提交；同步失败时分别恢复旧凭据与原文件字节／不存在状态，任何恢复不能确认时提示用户检查。凭据访问与配置写入通过同一宿主接口供生产和测试使用，测试仅用内存凭据，不访问真实Keychain。此补偿不宣称跨Keychain与文件在进程崩溃时具有原子提交保证，真实Keychain联调仍待验收。

默认无产品遥测、无云同步、无后台屏幕抓取。选择云模型时输入会离开本机并由服务商处理；服务商保留/训练规则按具体配置展示。诊断默认仅事件 ID、耗时、错误类别和版本，API key、prompt、clipboard、完整 CLI 输出不进入普通日志。用户分享诊断前可审阅内容。
