# AI 服务快速配置与应用图标

2026-11-27 用户反馈：AI 服务页要求先填写完整 API endpoint、token 参数和精确模型 ID，新用户无法像 OpenAI 客户端一样直接输入 key 并选择模型；正式应用缺少 Finder/Dock 图标。

## 交互合同

- 无已保存 endpoint 的新会话只在编辑草稿中预填 OpenAI 官方 endpoint，不写入持久配置、不自动请求网络。已保存 endpoint（包括 Responses 及自定义兼容服务）保持原样。
- 页面顶部按服务、密钥、连接与获取模型、默认模型、保存顺序展示。OpenAI 隐藏 endpoint；自定义兼容服务保留准确 endpoint 和匿名服务能力。明确切换服务时清除旧草稿 key 与默认模型，取消旧模型清单；不得向另一个地址发送旧密钥。场景/动作覆盖与现有配置不隐式删除。
- 使用现有受限 GET /models 客户端；只在用户点击获取模型时发送请求。官方推荐目录和账号返回的可用模型分别标识，搜索可按准确 ID；不将模型清单当作生成能力证明，不假定任意模型是最新或可用。已有模型即使不在清单仍可保留。支持手工输入精确 ID。
- 快速保存需要有效 endpoint、默认模型及 OpenAI key（或该准确已保存服务的凭据）；保存通过现有事务和 Keychain，不引入新的凭据持久化。网络失败与取消保持旧活动设置。高级设置、各场景覆盖与费率仍可显式展开。
- macOS AppIcon 使用蓝紫玻璃、钥匙、启动坞、智能星光视觉；透明外缘、标准 16–1024 像素 ICNS，多分辨率；正式、Preview、Desktop Review 使用同一品牌资源，仍保持各自 bundle 身份。保留可维护图标生成源，系统菜单栏单色入口不改。

## 验收

验证新用户草稿、已有配置保留、服务切换密钥隔离、官方/自定义模型清单、保存和失败边界，检查中英文案、构建后 Info.plist 和实际 AppIcon.icns。真实服务鉴权与原生视觉须单独记录，不把合成清单/编译通过当成真实用户密钥可用。发行沿用本地 ship 与同源门禁。
