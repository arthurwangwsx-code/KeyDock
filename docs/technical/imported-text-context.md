# 导入文本上下文

2026-11-25，alpha.10已发行，真实系统验收仍依状态总账。Tools保留一个替换式文本输入槽，不是多附件或多模态上传。显式文件选择、区域OCR与MCP资源／提示词沿用原授权和提取边界；AiBox仅作为设计参考，没有复制私有源代码。

`TextContextInput`把正文、正文revision与可选`TextContextProvenance`作为一个值原子发布。来源包括提取类型、名称、捕获时间、来源UUID、正文revision／字节数、已编辑状态及可选MCP来源ID；不保存文件路径、选定URI、句柄或授权。文件类型由实际提取分支判断，MCP展示已选服务器与具体项目名称。外部名称是有界普通数据，不作为提示词、执行指令或权限。

每个活跃Tools槽单独预留128KiB正文与2KiB来源空间，纳入既有32MiB会话逻辑预算。单名称上限512 UTF8字节；整次超限拒收，正文不截断。草稿的来源字节另计入草稿接纳和保留，任务来源位于原执行元数据预算内。逻辑预算不保证RSS。

文档导入先授权，再把任务／输出／输入快照与新增文本槽一次接纳，成功后才提交所有权与代次；任务容量或完整预算不足不先逐出旧草稿。MCP先检查连接／busy并占用操作，再同步接纳来源槽；提示词参数在此前使用与客户端相同的纯校验，冻结字典。异步返回还需原代次、存活owner、当前来源配置和取消围栏成立。

Tools到AI以完整快照创建草稿。普通AI、命令建议与只读Agent冻结相同来源对象，不添加名称到网络消息。正文编辑按UTF8字节判断，新的revision标记“已编辑，来源”；来源不能产生AX替换目标。AI区分当前输入与运行输入，历史任务显示冻结来源；重启没有保留来源的任务明确显示未保留。

Tools“清除输入”移除本槽正文／来源并释放槽位，使迟到提取失效；AI“清除输入”清本草稿正文／来源／目标并增加revision。已有AI草稿和任务是独立历史，不因清Tools而被暗中删除。全量“清除已完成历史”在开始时清Tools与代次，原任务／草稿清理仍依已确认结果。普通导航和隐藏窗口保留输入；shutdown清Tools并取消／等待现有worker。后续候选增加[显式关闭活动草稿](../implementation/ai-draft-closing-2026-11-25.md)，单独确认、冻结文档、取消并等待真实worker，完成后释放输入；隐藏不触发它。

真实外部模型、OCR可靠性、系统权限、完整双语／辅助功能与长期驻留仍独立验收。合成回归与原生观察见[实现复查](../implementation/imported-text-context-2026-11-25.md)。
