# 有序命令集合

集合是常用动作的有序入口，没有工作流、批量执行或隐式授权语义。`CommandCollection`的JSON格式保持不变，最多32项唯一稳定引用；全局最多32个集合。

## 状态与保存

WorkspaceSession分别保存浏览集合ID和CollectionEditorDraft。草稿包含显式编辑ID、名称、有序commandIDs、候选过滤词及展开状态。只有Edit载入编辑身份；浏览Picker与Launcher深链接不修改草稿。成功持久化后整体重置并收起候选区，失败或导航／语言变化保留完整草稿。

勾选追加末尾，前移／后移按ID交换相邻位置，取消勾选或单项移除只删除该引用。过滤、候选截断和目录排序不修改顺序。失效引用保留位置和容量，保存明确拒绝；用户显式移除不可用项后，其余相对顺序保留。已删除的编辑目标不能通过旧草稿重建。新建上限不阻止编辑既有集合。

候选、保存和运行复用同一可用性判断：排除临时窗口／剪贴板项、集合引用，以及依赖原窗口目标的布局／窗口循环等动作。原有配置中的这些引用保留为不可用项，不能静默删除或运行；窗口动作继续从Launcher或直接快捷键运行。

保存／移除复用统一配置事务：写入成功才发布配置，写入前后抛错均补偿原文件；错误通过当前工作区的语义提示显示，草稿和原配置保留。不会因进入编辑、重排或保存而运行任何动作。

## 单项入口

普通动作仍经过统一execute／授权路径；固定命名应用动作保留。CLI使用已保存argv／cwd调用runCommand，显示工作区任务及明确失败，不调用Terminal GUI作为验证手段。

AI按钮明确为“打开AI工作台”。先按prepareAI授权，再创建空的manual草稿，target为nil，显示正确的AI输入页；不读取当前剪贴板、不复用Launcher选区、不调用隐藏Launcher的自动执行回调。用户之后选择输入并主动运行，真实API仍按既有决定稍后配置。

## 原生行身份

macOS Form会展开多个动态列表。浏览行和编辑行即使引用同一动作，也使用不同的typed ID作用域：saved(collectionID)与draft，加commandID；索引只决定显示编号，不参与身份。候选使用独立的CommandItem String ID。重排不能把运行按钮复用为编辑箭头。
