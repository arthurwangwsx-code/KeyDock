# 已保存动作的移除与引用

设置页分别管理保存命令与AI动作。移除是独立审阅页：显示准确目标和引用，允许取消与重新检查；不把Edit、Run或选择动作当作移除授权。每次打开使用独立呈现UUID，重新检查保持sheet身份与键盘绑定，只替换独立审阅UUID。取消按呈现身份收口，确认必须匹配当前审阅UUID；旧确认不能提交新快照，旧取消不能关闭另一次呈现。

移除确认冻结完整定义的排序JSON指纹；最终操作在MainActor同步重查目标与当前引用。定义变化、目标缺失或出现新引用时停止并留在审阅页，要求重新检查。没有自动级联删除。

| 引用 | 行为 |
|---|---|
| Workflow的savedCommand／aiAction UUID | 阻止移除并列出工作流 |
| Agent的allowedCommandIDs | 阻止保存命令移除；AI动作不属于此类型化引用 |
| Collection的完整command.UUID／ai.UUID | 阻止移除并列出集合 |
| Collection经workflow.UUID，Schedule经workflowID | 显示间接依赖；直接工作流引用已足以阻止移除，包括禁用计划 |

提示词或argv中的偶然UUID文本不作引用。首次查看与最终确认之间不假定引用不变；调度缓存滞后也不能绕过直接工作流引用检查。

无引用时，候选配置一次移除定义及准确完整命令ID的快捷键字典项、收藏、别名与最近项；AI自带快捷键随定义消失。复用commitShortcutConfiguration的候选OS注册、持久化和文件／注册补偿。成功后才关闭审阅页；补偿失败明确报告，不宣称完整回滚。这个事务不修改调度账本、凭据、usage、activity、历史或在途执行快照。

生产设置编辑器显式记录new／edit身份，Save重新检查当前编辑目标；被移除对象的旧编辑稿不能通过原Upsert接口隐式重建。新建与AI命令建议审阅使用新的明确创建意图，失败保留表单。原模型Upsert端口继续用于已授权的内部模型提交，不是新的外部自动化接口。

Agent保存拒绝失效的保存命令ID，未保存草稿显示可显式移除的失效工具。AI动作删除不改变任何草稿正文、revision或latestRunID；现有任务继续使用冻结设置，结果复制入口保留。新运行在动作失效时被拒绝，页面显示占位与选择提示，不偷偷替换为列表第一项。

## 片段、网页动作与集合

三类常用工具共用上述删除审阅及补偿事务。片段使用独立new／edit草稿；网页动作与集合的编辑稿冻结原定义指纹。保存前检查准确ID和UTF8字节指纹，目标删除或变化时保留字段并拒绝保存；只有显式New才产生新身份。集合对片段／网页动作的准确引用阻止删除，不自动改写集合。

常用工具的专用快捷入口先检查现存目录／版本，再交给执行策略；这些不需要原选区的入口不捕获选区或恢复旧目标。删除前的搜索结果不能执行或重新写回最近项。测试中的OS注册／上下文读端口为合成宿主，物理快捷键另行验收。

## 旧版遗留偏好修复

快捷键设置仅在存在遗留项时显示显式修复入口。从快捷键、收藏、别名、最近项四个容器取并集，仅识别规范`snippet.UUID`、`web.UUID`、`collection.UUID`，以配置定义数组判断是否缺失。未知ID、当前定义、禁用贡献、集合内容与执行历史均保留，不在解码时静默修正。

审阅显示完整ID、热键和偏好类别，不显示别名正文。最终确认重查完整快照，别名按准确UTF8字节参与指纹；新遗留项、恢复定义或偏好变化均使旧确认失效。四类偏好经同一补偿事务提交，失败保留审阅。设置页所有编辑／移除／修复入口互斥，待审命令先检查呈现能力再消费队列，迟到回调不能产生无人持有的active审阅。
