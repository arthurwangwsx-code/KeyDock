# 界面与交互规范 v0.3

2026-11-23 用户评审修订。初版大面板被拒绝；本规范取代初版单窗口导航。当前已实现与视觉待验项目分别见状态总账。

## 三种窗口

| 窗口 | 职责与入口 | 生命周期 |
|---|---|---|
| 启动台 Launcher | 全局快捷键／菜单栏打开；搜索应用、窗口、命令和 AI 动作；默认动作、收藏与指向当前对象的快捷键设置 | 680×456 pt 浮层；Esc 收起并恢复仍有效的原目标；外部失焦收起，不抢回焦点 |
| 设置 Settings | 菜单栏“设置…”、⌘,、启动台齿轮 | 独立标准窗口；通用、快捷键、AI 服务、AI 动作、命令、剪贴板、隐私、关于；保留上次分类 |
| 工作区 Workspace | 菜单栏、启动台任务入口、AI“在工作区打开” | 独立可调整窗口；管理任务、AI 文档与剪贴板；关闭窗口不取消任务 |

启动台不承担配置管理。保存命令默认执行，动作文字显示“运行”；应用显示“打开”，窗口显示“切换”。编辑与权限设置通过明确入口进入设置。空查询隐藏窗口标题，优先按收藏／最近排序安全候选；有查询时显示完整结果，方向键可遍历全部结果并自动滚动。

## 视觉系统

采用AppKit／SwiftUI系统组件，启动台使用原生glassEffect regular材质，整块面板不设置interactive；操作控件按角色采用系统样式，26+做availability检查并在当前27主机观察。玻璃用于浮层和关键功能控件；设置与工作区使用系统侧栏、工具栏、Form和稳定正文背景。hosting与输入控件身份固定，系统辅助功能变化只改变材料参数。

基准：启动台外圆角24 pt，搜索字号22，结果主文字13／辅助11，行高50，内容边距12–24，底栏44，图标点击区域30。颜色使用系统语义色；应用结果使用实际应用图标；选中态、键帽、结果分组、键盘提示、阅读表面、图标按钮、内联提示、空态由 KeyDockUI 统一提供。高对比度提高自绘边界和选中填充；非选中分类文案采用secondary。玻璃容器内部的按钮不重复叠玻璃，系统toolbar保留原生样式。减少透明度时使用实色表面，减少动态效果时关闭自定义动画；控件效果由系统适配。macOS 14–25 使用系统 NSVisualEffectView 回退。

依据 Apple 的 [Liquid Glass 指南](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)、[NSGlassEffectView](https://developer.apple.com/documentation/appkit/nsglasseffectview) 和[设置设计指南](https://developer.apple.com/design/human-interface-guidelines/settings)。系统原生材质是否达到预期仍需实际观察，不能由调用 API 推定视觉质量。

## 交互与状态

- 搜索立即获得焦点；中文输入法组合期间 Return／Esc／方向键交回输入法；⌘K 打开所选结果的动作菜单。
- 同一次启动台展示保留原应用和选区；捕获进行时排队 AI 执行；新展示创建新快照，不能覆盖旧结果的替换目标。
- 启动台和工作区引用同一 AI 草稿文档。输入、动作选择推进 revision；结果保存运行时模型、动作和来源；改动作清除当前结果选择，旧任务仍留工作区。
- AI 未得到选区时明确提示输入；失败／取消显示终态；仅完成的结果可提供原选区替换。
- AI 命令建议只进入设置的待审草稿队列，不自动抢焦点、不覆盖未保存表单、不自动执行。
- 每个窗口拥有搜索、选择和导航状态；API key 输入只归设置会话，关闭设置后清空；操作反馈归设置、工作区或具体草稿。
- 菜单栏“工作区”只显示现有页面，启动台任务入口才显式跳转任务；应用菜单提供“关于KeyDock／设置／退出”。
- AI输入使用⌘Return运行、⌘.停止；工作区⌘N新建并聚焦空白输入，工具栏草稿菜单可返回本次运行中仍保留的草稿。草稿受会话保留上限与清除策略约束。
- 命令保存失败保留表单；语言／外观先持久化再更新界面。剪贴板暂停即时生效，保存失败仍暂停本次采集并明确说明重启边界。
- 标准菜单提供关闭窗口、撤销、重做、剪切、复制、粘贴和全选。单一菜单栏图标始终提供启动台、工作区、设置与退出入口。

## 中英文

支持跟随系统、English、简体中文，设置中即时切换；窗口、菜单、占位符、内置动作、状态和提示使用同一语言设置。每个 target 拥有自己的 String Catalog，UI 库由调用方传入文案。系统语言在App下次启动时重新解析，App／Feature／SwiftUI locale使用同一受支持语言；应用内English／中文选择即时生效。应用提示保存语义key并在显示时翻译；用户自定义命令、提示词、模型名和输出按原文显示。系统权限说明有en／zh-Hans资源，弹窗语言由macOS决定。旧内置动作按原始名称加原始 prompt 保守迁移，保护用户改名。
