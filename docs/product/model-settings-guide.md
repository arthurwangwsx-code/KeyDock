# 模型、场景与思考设置

全新配置的服务端点与模型为空。初始输出上限为 2048，思考强度跟随模型。已有安装保存的模型、思考与上限按自己的配置加载。开发版的场景覆盖开关沿用全局输出上限；动作或 Agent 打开覆盖时，沿用该场景当前的上限。关闭覆盖后，后续新运行继续随上级变化。兼容服务列出一个目录同名模型时，设置仍会注明该服务已列出它、能力有待核实。

从菜单栏打开设置，进入“AI服务”。先填完整端点，再输入密钥；改变端点会清空尚未保存的密钥。密钥已保存时留空即可保留，只修改模型或参数仍需点击“保存API配置”，看到保存成功提示。

全局默认用于未另行配置的场景。翻译、总结、命令解释／建议、只读Agent、Agent配置、使用分析和工作流AI步骤可分别设置；普通自定义文本动作也有独立场景。字段按定义覆盖→场景→全局逐项继承。动作及Agent编辑器可独立覆盖模型、协议、思考和输出上限；页面会显示实际生效值与模型来源。工作流的AI步骤先保留引用动作的显式覆盖，再继承工作流场景。

“跟随上级”“模型默认”和“关闭思考”含义不同：前者继续继承，模型默认省略强度参数，关闭思考则明确发送none。只按已知能力提供新选择；旧不兼容值保留并提示不能运行，不静默换档。Sol／Astra不能关闭思考；Luna／Terra支持none。推荐目录依据[官方部署说明](https://developers.openai.com/api/docs/guides/deployment-checklist)，核对日2026-11-26，不把工具内部档位当公共API选项。

本机已验证的示例为全局Sol low、翻译Luna none，均使用4096输出上限。输出上限包含思考token；较高强度可能先耗尽预算。界面不会自动增加上限。自动协议为已知模型选择匹配路径，工具调用仍须经过原授权。其他兼容API可选协议及准确模型ID；未知服务的思考兼容声明仅在服务商已确认支持时显式启用，绑定准确服务。

点击“刷新模型清单”才向当前服务请求ID；打开页面不自动联网。推荐目录、服务返回ID和当前手填值合并显示，当前选择即使未返回仍保留。清单可能包含图片、语音等模型，返回并不证明支持当前文本动作或思考／工具能力，请按服务文档选择。清单仅在本次会话保留，服务或凭据变更后重新刷新；刷新不保存或更改模型设置，不计作AI token调用。

自定义端点若不能准确推导清单地址，继续手填ID。鉴权、限流、超限或超时会给固定提示；失败保留同服务上次清单和选择。服务清单不提供价格：费率仍由用户可选填写，未知时显示未知，估算不等于账单。已运行任务继续使用开始时冻结的设置，新设置用于之后的运行。
