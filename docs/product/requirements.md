## 核心对象

`App / Window / File / URL / ClipboardItem / SavedCommand / AIAction / AgentDefinition / Workflow / Capture` 都拥有稳定 ID 和可用动作。搜索结果是对象投影；Command 是用户动作入口，Tool 是 Agent 可调用的结构化能力，双方通过同一执行服务做事。对象正文不因被索引而自动送往模型。

## 用户流程

### A. 唤起与窗口切换
用户按可配置快捷键（建议初始 Option+Space，冲突时让用户修改）→ 输入应用或窗口关键字 → 上下键选择 → Return 切换，Esc 收起并恢复原焦点。输入法组合输入期间不误触执行；慢 Provider 不让已有结果消失。窗口关闭/权限撤销时显示原因，不能切到复用同 PID 的错误窗口。

### B. 运行命令行工具
用户搜索保存的命令 → 参数表单展示 cwd、executable 和参数 → 执行后可收起面板，在任务区看到输出/退出码/取消。一次性命令交给 Process；ssh/vim/top 和交互式 AI CLI 通过终端打开。临时 shell 必须进入明确模式；模型输出不能未经检查直接变成 shell 命令。

### C. 剪贴板管理
首次由用户启用 → 记录符合过滤规则的纯文本 → 搜索/预览/复制。自动粘贴为单独动作，权限不足时复制仍可用。默认跳过 concealed/transient/已配置排除源，暂停、单条删除、全部清除和保留期从首版提供。剪贴板历史不默认成为 AI 上下文。

### D. 快捷 AI 翻译与总结
用户创建动作“翻译成中文”：指定选区输入、目标语言、模型/endpoint、提示词、结果展示方式和自定义快捷键。按键后捕获选区并显示来源提示，按已保存范围直接发出请求，结果流式进入轻量结果面板。可复制、改语言、重试或固定到任务区；替换选区是明确动作，需要重新核对目标。没有选区时提示选择输入，不默认读取整个窗口或完整剪贴板历史。

快捷键示例仅示意，不自动占用系统组合：`Ctrl+Option+T` 翻译选区、`Ctrl+Option+S` 总结选区。用户可以给任意 AIAction、SavedCommand 或 Workflow 设置独立快捷键；冲突、禁用和失效在设置中可见。

### E. AI 扩展命令
用户输入“列出当前项目最近修改的文件” → AI 生成结构化草稿，显示命令、参数、目录、解释和影响 → 用户运行 → 结果可交给“解释输出”动作。AI 推断 cwd 不具授权效力；无确定目录时要求选择。保存为新快捷命令仍需用户命名和检查，不能自行安装依赖或改 shell 配置。

### F. 使用分析与 Agent
个人洞察默认分析 KeyDock 内的最小事件，展示日期区间、统计口径、缺失数据与建议依据；用户选择后才把聚合数据送 AI。全电脑活动分析属于另行启用的 P4 能力，不默认采集窗口标题或浏览历史。

Agent 任务进入独立任务区：显示目标、允许工具、预算、当前步骤和输出，遇到所需权限暂停，允许取消。模型看见网页、OCR 或工具返回的指令不能扩大工具范围。恢复时展示已完成动作和不确定动作，避免重做写入或发送。

## 交互规格

搜索面板、动作面板、参数表单、详情/结果、任务区和设置共享组件。短动作不强迫进入聊天；长任务有持久入口。支持深浅色、VoiceOver、键盘完整操作、中文/英文 String Catalog 和大字体。成功、拒绝、超时、目标失效、模型限流、离线、用户取消分别表达。

## v0.1 非目标

不开发云账号/同步服务，不迁 AiBox 私有账户通道，不默认持续录屏，不自动运行未审查扩展，不首期实现第三方 JS UI runtime 或完整 Raycast API 兼容。上述取舍不取消长期通用 Agent、工作流和常用工具的方向。
