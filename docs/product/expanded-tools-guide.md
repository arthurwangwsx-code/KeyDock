# KeyDock扩展能力使用说明

这是当前源码中的使用流程，发布版本与真实系统验收见状态总账。所有功能共用启动台、独立设置与任务工作区，中英文界面可在通用设置切换。

## 快捷操作

剪贴板历史有独立两栏面板，可从启动台、菜单栏打开；在设置→快捷键的“剪贴板历史”一行录制专用组合，并可设置搜索别名。现有配置不自动增加新的系统级绑定。打开后直接搜索，↑↓选择并预览，Return请求插入原应用，⌘Return复制，Esc返回。记录默认关闭；面板不会因打开就开启采集。

插入需要可验证的原文本输入位置、辅助功能／事件权限且Secure Input关闭；不满足时仍可明确复制。所选纯文本保留在当前剪贴板，不读取旧正文或定时恢复；请求已发送不保证其他应用已消费或保存。真实插入与物理热键验收状态见总账。快捷键页可切换应用、窗口管理、AI、命令和工具分类，13项布局无需先收藏。

启动台搜索应用、窗口、保存命令、AI动作、工作流、Snippet、URL动作或命令集合；均可从快捷键设置绑定。输入算式可复制结果，输入`10 km to mi`等可换算长度／质量／温度／数据单位。MB与MiB不同，只做有界数值换算，不执行表达式之外的脚本。

窗口布局作用于唤起前的窗口，支持半屏、四角、最大化、居中、跨屏与恢复。需要用户在macOS中授予Accessibility；目标过期、不支持调整或写后读回不一致时明确失败。未完成真实多屏和权限撤销矩阵。

当前alpha.6源码还提供当前应用的上一／下一窗口及最小化，均可在快捷键→窗口管理中绑定。应用／窗口快捷键直接执行；失败与未知结果保留在工作区任务中。实际全局热键、AX及多屏验收状态仍见总账。

设置→应用动作可以创建同一应用的多个命名动作，分别选择启动／激活、前台隐藏否则显示、隐藏、显示、显示所有窗口或正常退出，再设置快捷键、别名和收藏。新建时必须明确选应用。正常退出只请求一次；应用可能拒绝或等待保存，须目标实例实际结束才显示确认。显示所有窗口不承诺还原最小化或跨Spaces。菜单「显示／View」也能直接打开Launcher、剪贴板与工作区。

## AI与Agent

设置页支持自定义兼容Chat Completions API的endpoint、模型和Keychain密钥。翻译／总结／解释输出等动作可自定义提示词与快捷键；未配置服务时本地工具仍可运行。真实外部API按用户决定稍后配置，本轮验证使用合成服务。

Agent页保存不同配置：指令、模型、工具选择与预算。可加入已审阅的保存命令和已连接的MCP工具。运行后进入统一任务详情，每次有副作用的工具调用显示完整目标／参数并单次批准。停止会等待真实进程或网络收口；暂停后的新尝试可能重复已完成步骤，需要用户明确发起。

MCP来源在独立设置页登记、启停和连接；stdio来源须明确受信任。Agent页还需逐工具选择，发现新工具不会自动进入授权。资源／提示词在工具页显式读取为预览文本，不自动发送AI。ACP尚未实现，普通交互CLI仍交给用户终端。

## 工作流与调度

工作流按顺序组合保存命令、AI动作、文本变换或手动输入，可使用初始输入、前一步输出或固定文字。执行使用启动时快照；修改定义不改变在途任务。命令中完整的`{{input}}`参数可绑定文本，执行前显示解析后的完整命令并审批；不做shell插值。

计划默认禁用。选择interval或明确时区的每日时间，保存后审阅命令和AI目的地，再启用。只在App运行期间派发；睡眠漏跑合并为一次。命令／工作流／AI目标改变后暂停，unknown结果需人工核对，不自动重试旧计划点。

## 工具与分析

工具页可导入单个文本、PDF文本层或图片；图片通过本地Vision OCR提取，区域截图需要Screen Recording权限。结果可检查、编辑、清除，再明确选择AI动作；不自动上传原图或记录截图历史。

Snippets只在主动选择时复制，不监听打字。文件搜索只访问所选目录、只匹配文件名，跳过隐藏项／包内容／符号链接；结果复核后仅在Finder显示。URL动作只支持HTTP／HTTPS，搜索模板对查询文本编码。命令集合组织常用动作，每个动作单独触发，打开集合不会批量执行。

使用分析默认关闭。启用后记录KeyDock内动作的最小元数据，最多30天；可以暂停、清除和导出聚合。报告明确只有部分覆盖，不能推断整机活动。只有点击“用AI总结”才发送当前聚合报告；原始正文、参数、窗口标题不会进入统计。
