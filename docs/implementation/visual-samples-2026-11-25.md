# 隔离视觉样例与原生复查

2026-11-25。延续`fix/ui-semantics-and-text-sync`，主Agent独占修改／构建／设备，子Agent只读评审。正式安装和公开Release仍为alpha.7；本轮是alpha.8候选的隔离Preview，未关闭OCR发行阻挡。

## 实现与边界

新增进程内的跟随系统、高对比、实色表面、减少动画和全部样例。仅Preview编译条件、safeSmoke与隔离Info标记、preview bundle及BuildInfo profile全部一致时允许；普通构建和不完整身份拒绝切换。样例不写UserDefaults、OS偏好、TCC或配置文件。系统真实需求通过OR始终保留，样例只能增强自有组件的相应分支。

四窗口及独立工作区工具栏共用状态，由固定宿主发布独立环境键；SDK只读的系统环境值不使用非公开setter。剪贴板选中行采用更强边界，实色模式提高正文背景不透明度，合并移动／移除的辅助名称带当前位置。原生菜单、系统控件、工具栏玻璃、系统动画及VoiceOver行为不由这些样例模拟。

## 已观察的原生子集

- 中文浅色剪贴板用三个自建合成记录，查询`KeyDock`得到两项，逐项勾选后为2/20；切换全部样例及恢复默认时，查询、顺序、合并正文与勾选保留。截图可见选中边界加强、正文使用实色阅读背景，移动／移除AX名称区分1和2。
- 英文深色面板以Shift-Return、Down、Shift-Return选择两项，切换全部样例及恢复默认后仍保持2/20、选中行和正文。英文菜单、面板及独立设置页实际截图已检查；这里只覆盖860×540面板和740×582设置页等观察尺寸，未宣称四组合全部窗口完成。
- 中文AI工作台输入合成`Synthetic KeyDock visual draft.`并选中`KeyDock`，样例往返后正文与选区保持。未运行AI或读取剪贴板；真实API保持未配置。
- 最终样例、语言与外观均恢复跟随系统。剪贴板记录采集仍停用，未复制／插入／删除条目，未修改排除名单或请求权限。

样例切换与关闭后重新打开面板是不同操作；重新打开按既有会话合同重置一次选择，本次不把它当作样例引发的丢失。

## 工具异常与未完成

首轮剪贴板搜索后工具读取发生30秒超时；重取精确App路径也一度超时。只读检查确认自有Preview进程仍在、没有新增崩溃报告；仅对该进程采集1秒栈，主线程包含AppKit／SwiftUI布局，不能由此确定根因。原生连接后续恢复，重新读取明确看到已写入的查询，随后完成上述交互；没有force kill、服务重置或TCC变更。一次设置入口点击返回AXError后，回查已进入设置，没有重复提交。

另有两次连续使用旧AX索引被工具拒绝；已先回查实际状态，再按新索引操作，没有据拒绝重复业务写入。工具超时／索引错误不当作产品通过，也未证实为产品死锁。

定向单元检查及原生截图只支持本文范围。真实OS增加对比度／减少透明度／减少动态效果、VoiceOver、中文组合输入、所有窗口／尺寸／深浅色组合、最低macOS版本与长期性能仍保持PARTIAL。完整本机OCR失败与发行未放行继续见[复发记录](ocr-recurrence-2026-11-25.md)。
