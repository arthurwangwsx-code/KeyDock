# 会话保留与清除复查

2026-11-23，feature/phase-one，基线 e96e5e8 后的本轮增量。第一阶段 P0+P1 目标不变，整体仍为 PARTIAL；本轮没有真实外部 API、钥匙串或个人剪贴板联调。

实现了[会话与元数据保留](../technical/session-retention.md)：统一 8 个 CLI/AI 槽位、200 条任务、32 份草稿、32 MiB 会话文本预算；保留可见结果、活跃输入与待审提案；128 KiB 输入拒收保留旧草稿；10 份提案包含正在审阅的源数据。任务回执及用量增加 90 天、数量和字节维护。设置隐私页增加两个独立确认清除入口，各存储失败分别保留并报告，不自动重放或停止终端命令。

独立复查发现并修正：同一可见文档换运行后保护引用过时；提案进入编辑器后脱离预算；清除等待期间删除新编辑；恢复被 generation 取消后不启动每日维护；用量文件已删但收口任务缓存未清；目录检查后路径替换的写入窗口。对应定向回归已进入主仓。Core 通过目录 FD 固定原对象；usage 通过不跟随链接的相对 I/O 管理专用目录。

第一次全量运行有两项旧故障夹具失败（measurement `aed88343-93d5-4734-83d5-8b2098f4d48f`，日志 `.local/p1-retention-full-first-failure.log`）。旧夹具通过移动目录制造写失败；固定目录对象后原目录仍可写，这个动作已不再构成写失败。现改为阻断实际 invocations.json 条目，继续验证“意图写失败无网络”和“终态写失败保留结果并告警”，未削弱断言。初版新清除测试还因 await 位于断言短路表达式右侧编译失败（measurement `2ab79787-8ba9-489c-bf79-9ac20d223d1b`），已改为先取得异步快照再断言；失败测量保留。
