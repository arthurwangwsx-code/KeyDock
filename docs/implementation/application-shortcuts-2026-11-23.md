# 应用索引与配置事务复查

日期：2026-11-23。基于 feature/phase-one 的本轮增量；P0+P1 整体仍为 PARTIAL。本轮不替代用户视觉评审或物理快捷键验收。

## 应用列表与响应

应用索引改为后台缓存。仅扫描 `/Applications`、`/System/Applications`、`~/Applications`；启动台首帧先显示内置能力，不等待扫描或监听器建立。已存在目录使用 FSEvents；缺失目录只观察最近存在父目录的条目变化，避免递归观察用户主目录。挂载变化、30 秒缓存期限和设置中的刷新入口提供补充刷新。

同名称或同 bundle identifier 的不同副本保留，行内展示路径；物理身份相同的符号链接去重。条目附带目录身份 revision，执行时同时核对选中条目、当前缓存与文件系统，拒绝移走、卸载和同路径替换后的旧动作。该机制不是代码签名或安全沙箱验证。

22 项 scanner/catalog/observer 合成测试，以及 1 项生产 Store→Launcher 查询集成测试通过。覆盖目录新建/移走、缺失根逐级建立、无关后代不触发父目录监听、停止后迟到事件、监听挂接期间安装变化、缓存错误保留与旧身份拒绝。最初的监听升级测试复现超时后，修正为监听就绪再重扫；全套运行还发现查询测试在新批次生成前过早断言，现等待完整批次后检查。失败测量仍在 iSpec，不用失败的瞬间加载状态推定产品错误。

## 快捷键与配置

快捷键按整个计划提交，支持交换绑定与重复项预检。每次注册使用新的 OS 事件 token，旧队列事件不能调用新动作。录制结束先恢复旧计划再提交候选；失焦结束录制。系统注册或文件写入失败时分别补偿，任一恢复失败都明确提示；无法恢复已保存的 OS 方案时停用全部并提供重试。设置保留未保存的 AI 动作，失效应用的快捷键可单独删除。

API 配置保存前记录目标 endpoint 的原凭据及配置文件原始字节/不存在状态；写入前后抛错均分别尝试补偿。只在成功后发布新配置；不完整回滚有专门提示。8 项 API 配置、6 项快捷键配置与 7 项 HotkeyCenter 合成回归通过。未使用真实钥匙串，不承诺钥匙串与普通文件跨进程崩溃原子性。
