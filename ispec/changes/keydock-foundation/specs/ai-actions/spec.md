## ADDED Requirements

### Requirement: 统一模型目录与场景设置
系统 MUST 提供准确可选模型、全局默认、场景与定义覆盖，按有日期的能力目录显示思考设置；实际请求、授权和用量共用冻结解析结果，不能只改变UI。

#### Scenario: 开启输出上限覆盖
- **WHEN** 场景、动作或 Agent 首次开启输出上限覆盖
- **THEN** 新值采用当前上级的有效数字，服务或模型尚未填写时也可配置；关闭后恢复上级，已有显式值不被重置

#### Scenario: 继承与模型默认
- **WHEN** 用户选择跟随上级、模型默认或明确思考强度
- **THEN** 分别继承、省略参数或发送支持值；不把默认等同none，不静默降低不兼容强度

#### Scenario: 最新模型协议不同
- **WHEN** 选择的模型仅在Responses支持工具调用
- **THEN** 通过已验证的Responses adapter和原Broker执行；未支持时派发前拒绝，不以Chat文本通过声称工具兼容

#### Scenario: 定义与运行设置变化
- **WHEN** 全局／场景／定义的模型、思考、语言或策略变化
- **THEN** 旧pending快捷键、attempt与调度批准失效；已开始的多轮请求保持冻结设置，不复用旧授权

#### Scenario: 机器输入的输出语言
- **WHEN** 将聚合JSON发送给模型生成使用洞察
- **THEN** 在开始前冻结明确输出语言；运行中切换界面语言不改变在途指令，未知覆盖仍保持未知

#### Scenario: 旧配置与自定义模型
- **WHEN** 读取旧配置、目录刷新或模型不再出现在目录
- **THEN** 保留准确自定义选择及显式覆盖，迁移不丢数据；旧reader不得重写丢失新模型设置，安装／回退门禁明确拒绝不兼容

### Requirement: 外部 API 与模型能力协商
系统 SHALL 提供独立 ProviderGateway、Keychain 凭据、流式结果、超时/取消和明确的模型能力描述，API 未配置时本地工具仍可用。

#### Scenario: Provider 未返回用量
- **WHEN** 模型成功返回文本但无 usage
- **THEN** 系统显示未知用量/费用或明确标识估算，不记为实际零消耗

### Requirement: 翻译总结快捷动作
P1 系统 MUST 支持用户保存输入来源、提示词、语言/参数、模型、输出方式和快捷键，按已配置范围运行。

#### Scenario: 翻译当前选区
- **WHEN** 用户触发选区翻译快捷键，目标有效且存在可读选区
- **THEN** 系统仅发送该选区与动作必要参数到配置的 endpoint，流式显示结果并允许复制

#### Scenario: 选区缺失
- **WHEN** 动作要求选区但目标不提供可读选区
- **THEN** 系统提示选择/复制输入，不自动读取整个窗口、截图或剪贴板历史

#### Scenario: 替换目标变化
- **WHEN** 结果返回后原选区/窗口已改变，用户选择替换
- **THEN** 系统停止写入并保留结果，不向当前任意窗口粘贴

### Requirement: 命令草稿与执行分离
系统 MUST 把 AI 建议表达为可审阅的 CommandProposal，真实运行经用户动作和 ToolBroker。

#### Scenario: 模型建议运行命令
- **WHEN** 模型返回 executable、argv、cwd 与解释
- **THEN** 系统展示草稿，在用户运行之前不启动进程、不安装依赖、不修改 shell 配置

#### Scenario: 等价Unicode输入已被编辑
- **WHEN** 用户把输入改成规范等价但UTF8字节不同的文本，旧请求仍未返回
- **THEN** 系统保留新文本的准确字节并增加revision；旧请求可以记录其结果事实，但不能替当前输入采纳命令建议或改变当前提示

#### Scenario: 输入法仍在组字
- **WHEN** 当前编辑器存在marked text，用户触发运行菜单、提交快捷键或运行按钮
- **THEN** 用户输入提交不创建请求、任务或进程；组字结束后允许重新提交，已冻结的后台工作流不受其他编辑器组字影响

### Requirement: 用量保留与清除
P1 系统 SHALL 为无正文的用量元数据提供90天、数量和字节维护及独立清除，缺报/损坏不记实际零消耗，删除必须同步使旧缓存与迟到恢复失效。

#### Scenario: 自动过期与迟到读取
- **WHEN** 用量记录过期或被用户清除，而旧读取仍在等待返回
- **THEN** 系统移除已确认删除的旧数值，不让迟到读取复活它们；新请求后续产生的用量属于新事实

#### Scenario: 收口期间清除或部分删除失败
- **WHEN** 已保存用量的请求仍在收口时用户清除，或部分文件无法删除
- **THEN** 系统按真实删除结果清理磁盘和缓存，对残留记录明确报告部分完成，不把仍在收口当作保留已删旧缓存的理由

#### Scenario: 任务回执快照晚于用量清除发布
- **WHEN** 启动或任务清理的回执读取在用量清除前开始，或在清除期间取得快照，清除完成后才恢复到界面
- **THEN** 系统保留任务、阈值和恢复图身份，但旧消耗、轮数及派生剩余额度保持未知；不能以恢复时的当前代次重新授权旧快照

#### Scenario: 清除后取得的新鲜读取
- **WHEN** 清除已完成，之后开始新的用量读取或真实worker产生新事实
- **THEN** 当前有效数值可以发布；历史恢复围栏不能永久封禁任务或修改在途meter，清除期间创建的读取不能因清除结束而变成有效

#### Scenario: 自动维护跨存储收口
- **WHEN** TTL、数量或字节维护选择已结束用量，预算回执仍保有数值，或MainActor报告尚未执行
- **THEN** 先持久化剥离候选预算数值，再确认删除对应ledger；读取围栏在维护事务内同步失效，旧回执和维护中取得的读取不能恢复消耗，阈值及恢复身份不变

#### Scenario: 在途与部分维护
- **WHEN** 被选用量仍有live owner，或预算写入／ledger删除／目录持久化失败
- **THEN** 不修改在途meter或删除尚未获准的ledger；保留与延后记录仍计容量，分别报告预算剥离、已确认删除、延后和失败，owner释放后可重试，进程中断不得留下已删ledger与旧预算

### Requirement: 明确导入文本的来源快照
系统 SHALL 在单个会话文本槽中保留有界的提取类型、来源名称与正文revision；来源仅用于说明，不能赋予文件、MCP工具或选区替换权限。用户明确选择AI动作之前不发送正文，来源标签不发送至模型或持久化回执。

#### Scenario: 导入文本进入AI
- **WHEN** 用户把文件正文、PDF文本、单图OCR、选区OCR或明确选定的MCP资源／提示词用于AI动作
- **THEN** 新草稿保留来源，普通AI／命令建议／只读Agent各自冻结运行时来源；编辑后的当前输入不改写旧任务事实

#### Scenario: 接纳被拒绝
- **WHEN** 新导入的任务和文本槽联合预算不足，MCP连接忙碌或提示词参数无效
- **THEN** 不逐出闲置草稿、不占用新文本槽、不更改原输入／来源／代次，也不读取文件或发起模型请求

#### Scenario: 编辑与清除输入
- **WHEN** 用户编辑导入正文、清除Tools输入或清除当前AI输入
- **THEN** 准确字节编辑增加revision并标记已编辑；清除同时移除正文与来源，迟到提取不能重新填入，旧任务事实按历史保留策略单独保留

#### Scenario: 显式关闭活动草稿
- **WHEN** 用户确认关闭一份AI草稿，即使随后导航到另一份或取消关闭调用者的等待
- **THEN** 确认仍仅指向原文档；立即阻止其新提交和迟到建议，撤销原选区替换，取消相关任务并等待实际worker收口后释放草稿；历史结果和独立命令编辑稿保留，其他草稿不受影响

### Requirement: 个人使用分析
P2 系统 SHALL 首先分析本工具最小事件和独立 AI 用量账本，云分析使用用户选择的聚合范围。

#### Scenario: 生成使用周报
- **WHEN** 用户选择日期区间并请求 AI 分析
- **THEN** 报告说明数据范围、覆盖缺口与统计依据，默认不附剪贴板正文、窗口标题或完整终端输出

### Requirement: 可选费率与逐调用估算
系统 SHALL 允许按准确服务与请求模型配置可选费率，冻结运行依据并为每次实际模型请求记录独立身份；费用必须标为基于已报告用量的本地估算，缺失或损坏不能冒充零或实际账单。

#### Scenario: 精确匹配且无价仍可运行
- **WHEN** 费率缺失，模型override或同host不同endpoint没有准确匹配
- **THEN** AI就绪判断与运行不被费率阻断，费用显示未知；保存费率不读凭据、不联网，不能借其他服务价格补齐

#### Scenario: 在途改价及逐请求身份
- **WHEN** Agent多轮或Workflow延迟步骤运行期间用户修改／移除费率，或新一次transport.open开始
- **THEN** 已启动run继续使用冻结服务／模型及费率集，每次实际open获得独立attempt并关联冻结依据；取消流消费者不能丢失已登记调用，发送前拒绝不伪造已发送用量

#### Scenario: 累计与部分事实
- **WHEN** usage累计快照重复、单边缺失、请求失败／取消，或产品后续解析／复制失败
- **THEN** 同attempt只合并计价一次，保留已知token及估算并明确未知部分；不撤销已报告用量，不将未知、溢出或不支持的delta计为零

#### Scenario: 提供方终态与本地会话结果

- **WHEN** Chat 或 Responses 已核实提供方成功终态，传输仍在排空或本地会话历史随后超限
- **THEN** 非封口用量快照立刻记录该 attempt 的成功和已报告数字，后续取消／失败保留该事实；产品完成事件仍等待传输排空和本地处理，后续轮可创建新 attempt

#### Scenario: 工作流归因与独立分析
- **WHEN** 父工作流包含多个模型或币种的AI子调用，用户查看任务与7／30／90天用量
- **THEN** 子调用保存准确parent／step归因，父汇总不重复入总计；分析读取有界账本，按币种分别显示小计、缺报与覆盖范围，不依赖当前任务列表或动作统计开关

#### Scenario: 历史与清除
- **WHEN** 重启读取旧文件／坏费率，或清除／TTL维护期间有迟到恢复
- **THEN** 历史只使用原快照，无快照不追套当前价格，坏费率不丢有效token；被确认删除的金额与分析缓存不复活，新增账本不含正文、工具参数或完整endpoint／query
